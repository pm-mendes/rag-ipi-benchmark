MITRE ATT&CK T1059 describes the adversary technique of using command and scripting interpreters, such as PowerShell, Bash, or Windows Command Shell, to execute arbitrary code and bypass security controls. Attackers often leverage these native tools to run scripts, download payloads, or automate malicious actions while blending in with legitimate administrative activity. This technique is widely observed because interpreters are pre-installed and trusted, making detection challenging.
