Retrieval-Augmented Generation (RAG) combines large language models with external knowledge retrieval. The architecture consists of three components: a document indexer that chunks and embeds documents into a vector store, a retriever that finds the top-k most similar documents to a query using cosine similarity, and a generator LLM that produces responses conditioned on retrieved context. Common vector databases include ChromaDB, Pinecone and Weaviate. RAG reduces hallucinations and allows knowledge updates without model retraining. The retrieval quality directly impacts response accuracy and security posture.
